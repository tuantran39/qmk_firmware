Bateer is an open-source project which aims to create custom keyboards from interesting ideas, as well as different form-factors.

Inside this directory you'll find support for the entire line of Bateer products.

* Maintainer: [Tran Ta Tuan](https://github.com/tuantran39)
* Hardware Supported:
  * [`The One`](the_one/): Bateer "The One" split-keyboard
